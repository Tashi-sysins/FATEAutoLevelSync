# FATE自動レベルシンク（FATEAutoLevelSync）

サーバー情報バーに「レベシンク: ON / OFF」を表示し、クリックで切り替える Dalamud プラグインです。
ON のときだけ、FATE に入ったら自動でレベルシンクします。

## 使い方

- サーバー情報バーの「レベシンク: ON / OFF」を**左クリック**で切り替え、**右クリック**で設定画面を開きます。
  Umbra のツールバーでサーバー情報バーの項目を表示している場合は、そこに出ます。
- 起動時・ログイン時は **OFF** から始まります（設定で前回の状態を戻すこともできます）。

| コマンド | 意味 |
|---|---|
| `/fatelevels` | 設定画面を開く |
| `/fatelevels on` | 自動レベルシンクを ON |
| `/fatelevels off` | 自動レベルシンクを OFF |
| `/fatelevels toggle` | ON/OFF を切り替え |

## 動き

ON のとき、次がそろったら `/levelsync on` を1回だけ送ります。

- ゲームが「いま参加している」と認識している FATE がある
- 通常のフィールドの通常の FATE（エウレカ・ボズヤ・クレセント・コスモ探索・季節イベントの FATE では動かない）
- 自分のレベルが FATE の上限より高く、まだシンクしていない
- 戦闘不能・会話中・騎乗中（設定で変えられる）ではない

- 一度シンクしたら、その FATE の中では、手動で解除しても掛け直しません（OFF → ON にすると、もう一度だけ判断します）。
- **OFF にしても、いまのレベルシンクは解除しません。** 解除の操作は一切しません。
- 同じ働きの機能を持つ別のプラグインを同時に有効にすると、こちらを OFF にしてもシンクが起きます。

## 設定

| 項目 | 既定 |
|---|---|
| サーバー情報バーに表示する | オン |
| ログイン時に前回の ON/OFF を戻す | オフ |
| 騎乗・飛行中でもシンクする | オフ（オフなら FATE の範囲で降りたときにシンク） |

## ビルド

.NET 10 SDK と Dalamud（XIVLauncher）が必要です。

```
dotnet build -c Release
```

環境変数 `FALS_DEPLOY_DIR` に開発プラグインの置き場を入れておくと、ビルドの後にそこへ写します。
